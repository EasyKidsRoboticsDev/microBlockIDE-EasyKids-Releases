# microBlock IDE EasyKids Releases

Windows and signed macOS installers and automatic update metadata.

- [Download releases](https://github.com/EasyKidsRoboticsDev/microBlockIDE-EasyKids-Releases/releases)
- [Source and release setup](https://github.com/EasyKidsRoboticsDev/microBlockIDE-EasyKids-Edition-Online/blob/main/DESKTOP-RELEASES.md)
- [Build status](https://github.com/EasyKidsRoboticsDev/microBlockIDE-EasyKids-Releases/actions)

The workflow checks the source version hourly. Windows builds automatically. To enable macOS, configure Apple signing/notarization secrets and the MACOS_RELEASE_ENABLED variable as described in the setup guide.
